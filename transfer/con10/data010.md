Discussion on Discussion on Metadata and Summary Embedding Process

- Reference Number Generation
  - Reference numbers will not be duplicated across meetings.
  - Each message will generate a unique reference number based on meeting ID.

- Embedding Process
  - Metadata embedding includes summary brief and description plan.
  - Cosine similarity is used for comparing embeddings.
  - Embedding dimensions are set to 1300.

- Hybrid Methodology
  - Hybrid methods are being used for embedding at multiple levels.
  - The process involves comparing metadata and summary embeddings.

- Query Processing
  - Queries can be processed directly to summary or meeting levels.
  - The design may allow for simultaneous processing of different paths.

- Testing and Validation
  - Extensive testing is required to ensure the system works effectively.
  - Results need to be validated against known data sets.

- Graph Embedding Proposal
  - A graph-based approach is proposed to enhance relationships between meetings.
  - Graph embeddings may help in efficiently retrieving related information.
